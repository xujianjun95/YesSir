## YesSir — 极简主义标签页管理专家 🛠

专为高频办公打造的 Chrome 扩展（Manifest V3）。
用修饰键把「关闭、切换、找回、归类」全部收进指尖，拒绝臃肿，回归跟手的效率。✨

🪟 高透毛玻璃 UI ・ 💊 后悔药 ・ 📊 使用统计看板 ・ 🧬 域名智能聚合 ・ 🤖 AI 标签分组

---

### 核心功能

- **快速关闭** — 按住修饰键，双击页面空白处关闭当前标签
- **切换面板** — 双击修饰键（或点击扩展图标）呼出 / 关闭标签切换面板
- **回到上一个** — 修饰键 + `E`，秒回刚才那个标签
- **后悔药** — 面板内「后悔药」按钮，一键找回最近关闭的 3 个标签
- **AI 智能分组** — 一键把杂乱的标签按主题自动聚类，告别标签海
- **域名聚合** — 同站点标签自动归并成组
- **语义搜索** — 在面板内按内容快速定位标签，并提供网页搜索建议
- **使用统计** — 可视化效率看板，回顾标签使用习惯

> 修饰键默认：macOS 为 `Command`，Windows / Linux 为 `Ctrl`，可在设置中自定义。
> 新用户无需自备 API Key 即可试用 AI 功能（每日免费额度），也可在设置中填入自己的 Key 解锁完整体验。
> 界面支持 简体中文 / English。
