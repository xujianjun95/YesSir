</br>支持在 Chrome 浏览器内通过修饰键来关闭或切换标签页
</br>关闭：按住修饰键双击页面空白处

</br>后悔药：双击修饰键，点击面板中的「后悔药」按钮，恢复最后关闭的 3 个标签页
</br>AI 分组：面板内点击「AI 聚合」，自动把标签按主题归类成 Chrome 原生标签组
</br>置顶 Dock：拖动标签到面板左右两侧的固定槽，高频标签随时取用
